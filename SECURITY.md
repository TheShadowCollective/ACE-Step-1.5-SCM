\# Security Policy



\## ACE-Step SCM Security Scope



ACE-Step SCM is a maintained fork of the original ACE-Step project created

specifically to support \*\*The Muser SCM\*\*.



Security vulnerabilities introduced by ACE-Step SCM-specific compatibility,

integration, environment-management, bootstrap, or API changes may be

reported through this repository.



If a vulnerability originates entirely within the original ACE-Step project

and is not caused or modified by ACE-Step SCM changes, it should also be

reported to the original ACE-Step maintainers through their responsible

disclosure process.



Likewise, vulnerabilities originating entirely within a third-party

dependency should normally be reported to the maintainers of that dependency.





\## Reporting a Vulnerability



We take security issues seriously and appreciate responsible disclosure.

If you discover a security vulnerability in \*\*ACE-Step SCM\*\*, please report

it responsibly through the private security reporting features available for

this repository.



Instead, use one of the following private channels:

* Open a **GitHub Security Advisory** for this repository (preferred)
* Or contact the maintainers directly if a private email channel is listed



Please include:

* A clear description of the issue
* Steps to reproduce (if applicable)
* Potential impact
* Any relevant proof-of-concept or logs

We will acknowledge receipt and work to assess the issue as quickly as possible.



\## Bug Bounties



At this time, \*\*ACE-Step SCM\*\* does **not** operate a formal bug bounty program.  
However, valid and responsibly disclosed security issues may be acknowledged in

release notes or documentation at the maintainers’ discretion.

Thank you for helping keep the project and its users safe.
